# Apresentar o beta

1. Abra ABRIR-APP.cmd ou a versão hospedada do HELP ALL.
2. Na entrada, preencha nome/apelido e cidade, aceite a informação de demonstração e clique em Criar perfil e experimentar.
3. Explore categorias, crie um pedido simulado, publique na comunidade e abra Help Coins.
4. Use Dar minha opinião para registrar feedback local; exporte os dados pelo perfil quando quiser guardar a sessão de apresentação.

O perfil beta é local, sem senha, e não é uma inscrição centralizada. Nenhum dado deste formulário é enviado ao Supabase. A atividade fica neste navegador; não há interação real entre dispositivos. Os 100 convidados são o público pretendido, não uma contagem de vagas confirmadas. HelpCoins e operações são ilustrativas.

O modo de apresentação está em PRESENTATION_BETA, no início de dist/app.js. O cadastro real está preservado no código para uma etapa posterior, mas não é acionado na apresentação beta. Não desative as regras do banco para liberar a demonstração.

A hospedagem atual permanece privada: Kevin consegue apresentar na própria tela. Acesso por link para convidados depende da configuração de compartilhamento do site.
